## Install

``` sh
pip install dseq
```

## How to use

### Read the bam file as a pandas dataframe

``` python
from dseq.tools import to_df
df=to_df(
    bam_path='inputs/test.bam', # path to the bam file
    contig='14',                # i.e. reference name/ target
    start=74846395,             # start position
    end=74846545,               # end position
    verbose=True,               # verbose
)
df.head(1)
```

## How to calculate

### Coverage per position (`QC`)

``` python
data=df.dseq.get_coverage()
data.head(1)
```

<div>


|     | reference position | reference | depth |
|-----|--------------------|-----------|-------|
| 0   | 74846395         | C         | 377   |

</div>

``` python
## plot
_=data.plot.area(
    x='reference position',
    y='depth',
    ylabel='depth',
    ylim=(data['depth'].max()+10,0),
    legend=False,
)
```

## Development

The package source is in `dseq/`. The tutorial (`examples/index.ipynb`)
imports from it; `examples/` also holds the docs configuration and the
example inputs.

``` sh
uv pip install -e ".[dev]"
pytest                      # unit tests (tests/) and the tutorial notebook
uvx ruff@0.17.2 check dseq tests
quarto render examples      # docs, into _docs/
```

### Release checklist

1.  Bump the version in `dseq/__init__.py` (`__version__`).
2.  Update `version` and `date-released` in `CITATION.cff` (checked by
    `tests/test_metadata.py`).
3.  Tag the release (e.g. `git tag v0.0.3 && git push --tags`).
